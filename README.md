# Bomban Futbol

لعبة كرة قدم مكتبية ثنائية الأبعاد مبنية بـ Flutter. تحتوي على محرك مباراة كامل، تحكم يدوي أو ذكاء اصطناعي، إدارة فرق ولاعبين، دوري، إحصائيات وحفظ محلي.

## أبرز الأنظمة

- مباريات دوري أو خروج مغلوب، وقت بدل ضائع، أشواط إضافية وركلات ترجيح.
- فيزياء للكرة الأرضية والهوائية والارتداد والعارضة.
- تسلل، لمسة يد، أخطاء، ركلات حرة، ركنيات، تماس وركلات مرمى.
- بطاقات صفراء وحمراء، إيقاف بالمباريات وإصابات وتبديلات اضطرارية.
- قوة تحمّل مستقلة `dayaniklilikGucu` تتحكم باحتمال الإصابة ومدة التعافي.
- VAR شامل للأهداف والتسلل ولمسة اليد والأخطاء والجزاءات والبطاقات، مع شريط زمني وعلامات لكل حدث، أزرار لإضافة القرارات عند الدقيقة المعروضة، وتصغير اللوحة أو تكبير منطقة الكرة حتى ×3.
- إحصائيات كاملة للاعبين مع احتساب دقائق البدلاء والتقييم و`zekaGucu`.
- 13 طقمًا جاهزًا، منها 10 ألوان وتصاميم إضافية.
- ثلاثة مستويات صعوبة وسبعة أساليب لعب للذكاء الاصطناعي، مع تمييز تصدي الحارس الواقف للكرات القريبة عن القفز للكرات الجانبية والعالية.
- دوري افتراضي من ثمانية فرق بنظام الذهاب والإياب.
- حسابات، ملكية فرق، تشكيلات، أطقم، لوحة إدارة ومحركات بحث.
- إعادة لقطات وVAR وإمكانية مراجعة الأهداف.

## التحكم أثناء المباراة

### الفريق الأزرق

- الحركة: الأسهم.
- التسديد: `Space` أو `Numpad 1`.
- التمرير: `Z` أو `Numpad 2`.
- التمرير الطويل: `X` أو `Numpad 3`.
- الضغط: `Numpad 0`، والدفاع: `Numpad .`.
- التبديلات: `F1`.

### الفريق الأحمر

- الحركة: `WASD`.
- التسديد: `O` أو `1`.
- التمرير: `P` أو `2`.
- التمرير الطويل: `L` أو `3`.
- الضغط: `0`، والدفاع: `` ` ``.
- التبديلات: `F2`.

اضغط مطولًا على التسديد أو التمرير الطويل لتحديد القوة. الركنيات والركلات الثابتة للفريق اليدوي لا تُنفذ تلقائيًا. عندما يمسك الحارس الكرة تظهر أزرار تمرير أرضي وعالٍ، وإذا لم يُنفّذ المستخدم ركلة المرمى يرسلها الحارس تلقائيًا بعد مهلة قصيرة. زر `Esc` يعرض نافذة تأكيد قبل مغادرة المباراة.

## الحفظ

يحفظ التطبيق البيانات بصيغة JSON في:

- Windows: `%APPDATA%/BombanFutbol/kayitli_oyuncular.json`
- عند غياب `APPDATA`: مجلد التشغيل الحالي.
